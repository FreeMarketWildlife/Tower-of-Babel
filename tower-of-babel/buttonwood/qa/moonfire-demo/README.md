# Playable survival event demo

Open `/tower-of-babel/?demo=moonfire`, then Resume. The demo starts paused,
with a 109m reinforced obsidian/deepslate/stone tower, finite resources and
seven Fey helpers assigned to Tower. Meteor fire and the red Moon arrive through
the normal event path. Options → Restart World replays this isolated fixture.

Reviewed against Buttonwood bible §§3–4 (native pixels and shared palette),
§8 (foreground tower against distant scenery), §§9–10 (existing controls and
truthful construction motion). No new icons, model scaling or collision
envelopes. Approved Use poses signal real placements. The demo is survival,
with finite resource counts and no infinite items or Worker bypass.

The separate `tower.moonfire.survival-demo.v1` save is chosen before loading core
or registering autosaves. The normal world and art sample remain separate.
`moonfire-demo-browser.test.cjs` checks isolated saves, pause-to-start, survival
flags, a supported tower, all seven Tower tasks, actual resource-consuming
construction by flying and ground animals, the winning ordinary event roll,
reload continuity, and a preserved normal-save sentinel.

[Live construction and shower](builders.png) captures an isolated test run after
15 active-play seconds. On initial load the player receives the paused start,
not an already-consumed meteor event.
